### Exact frozen x10 mathematics

For every required already-VALID snapshot:

```text
Mid = (Bid + Ask) / 2
```

```text

```

All targets, distances, strikes, mids, numerator, denominator, and the derived
ratio remain `Decimal` until only the final ratio is converted to Python

A numeric x10 requires `QualityStatus.VALID` for all four roles:


Any required non-VALID status returns `None`, including MISSING, STALE,
CROSSED, LOCKED, ZERO_BID, ZERO_SIZE, OUT_OF_ORDER, DUPLICATE, HALTED, and
UNKNOWN. No PUT candidate or no CALL candidate also returns `None`.

```text

invalid ATM fallback: NO
earlier-valid quote fallback: NO

```

A contradictory snapshot marked VALID still hard-fails through
`_valid_quote_mid(...)` for a missing quote, wrong source, wrong contract ID,
non-Decimal/non-finite/non-positive bid, or ask not strictly above bid.
