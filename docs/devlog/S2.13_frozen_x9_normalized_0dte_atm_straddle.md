### Exact frozen mathematics

```text
CALL mid:   (Bid_C + Ask_C) / 2
PUT mid:    (Bid_P + Ask_P) / 2
x9:         (C_mid + P_mid) / S_t
S_t:        dataset.session_state.spx_decision_px
```

Boundary bid/ask prices, both mids, the straddle sum, and normalization use
exact `Decimal` arithmetic. Only the final derived x9 is converted to Python
`float`, then required to be finite and strictly positive.

### Validity and integrity semantics

```text
Both selected snapshot qualities required: VALID
Any non-VALID selected side:               x9 = None
Absent CALL contract:                      x9 = None
Absent PUT contract:                       x9 = None
Empty listed chain:                        x9 = None
Numeric-zero sentinel:                     NO
NaN sentinel:                              NO
Fallback strike:                           NO
```

All non-VALID `QualityStatus` values, including MISSING, STALE, CROSSED,
LOCKED, ZERO_BID, ZERO_SIZE, OUT_OF_ORDER, DUPLICATE, HALTED, and UNKNOWN,
produce ordinary stage-local unavailability. A snapshot marked VALID but
missing its selected quote, referring to a different exact source-scoped
contract, or containing a non-Decimal/non-finite/non-positive/non-strict
bid/ask pair raises `OptionFeatureIntegrityError` as a contradictory bundle.

### Upstream quality ownership and feature-valid boundary

```text
As-of reselection:                         NO
Quote-age recalculation:                   NO
Quality reclassification:                 NO
Earlier-valid fallback:                    NO
Raw quotes:                                NO
Approved snapshot quality_status reused:   YES
Narrow VALID quote consistency checks:     YES
```

Frozen Data-Spec consequence: invalid or unavailable x9 must eventually make
`feature_valid = false` and prohibit a trade. S2.13 represents that ordinary
state locally as `None`. Full `feature_valid`, `invalid_reason`, feature
snapshot persistence, and the trade/no-trade decision are not implemented.
A later required-feature aggregation stage must map unavailable required x9
to `feature_valid=false`.
