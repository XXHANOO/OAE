The public stage API is exactly:

```text
x1 = ln(S_o / S_pc)
S_o  = dataset.session_state.spx_open
S_pc = dataset.session_state.spx_official_prev_close

x2 = ln(S_t / S_o)
S_t = dataset.session_state.spx_decision_px

x3 = ln(S_t / S_13:25_CLOSE)
Numerator   = canonical bar ending 13:30 close
Denominator = canonical bar ending 13:25 close
Interval    = 13:25 -> 13:30

x4 = ln(S_t / S_13:00_CLOSE)
Numerator   = canonical bar ending 13:30 close
Denominator = canonical bar ending 13:00 close
Interval    = 13:00 -> 13:30
```
