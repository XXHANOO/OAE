## 6. Implementation Details

Root cause: S2.07 used `bar_start_ts_utc < canonical_open` as its pre-open
exclusion. That silently treated a fully available 09:29:30–09:30:30 ET bar
as pure pre-open even though it intersects the canonical regular-session
window. The original off-grid test covered only a fully in-window malformed
interval and did not expose this opening-boundary case. Separately, SPXS-011
proved open greater than close rejection but did not independently prove open
equal to close rejection.

The builder now ignores a same-date bar as pure pre-open only when
`bar_end_ts_utc <= canonical_open`. A bar whose end is after the open and at
or before the decision has entered the fully available active horizon and
must match an exact expected interval. The existing future filter remains
before grid, quality, source, and duplicate inspection, so a bar ending after
the decision remains non-observable.

Repair matrix:

- 09:29:00–09:30:00: IGNORED AS PURE PRE-OPEN.
- 09:29:30–09:30:30: HARD FAIL — OFF-GRID ACTIVE-WINDOW OVERLAP.
- 09:30:00–09:31:00: VALID CANONICAL BAR.
- 13:29:00–13:30:00: VALID CANONICAL DECISION BAR.
- 13:29:30–13:30:30: NON-OBSERVABLE — NOT FULLY AVAILABLE AT DECISION.
- 13:30:00–13:31:00: NON-OBSERVABLE.
- `session_open_ts_utc == session_close_ts_utc`: VALIDATION FAILURE PROVED.
