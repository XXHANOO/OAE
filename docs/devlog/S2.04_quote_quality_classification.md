## 6. Implementation Details

`quote_age_seconds(quote_ts, decision_ts)` delegates directly to
`oae.temporal.age_seconds(...)`. It therefore rejects naive timestamps,
compares actual UTC instants independent of timezone representation, preserves
signed microsecond-resolution elapsed time, and performs no rounding,
clamping, millisecond conversion, or persistence.

`classify_quote_quality(quote, decision_ts, max_age_seconds)` accepts one
`OptionQuoteRecord`. It rejects booleans, non-finite values, negative values,
and every finite value not equal to the frozen 2.0-second threshold with
`ValueError`. The exact numeric values `2.0` and integer `2` are intentionally
accepted under normal Python numeric equality. The quote age is computed next;
any future quote fails closed with `ValueError` before a diagnostic status is
selected.

For a non-future quote, the classifier applies exactly this deterministic
diagnostic precedence:

```text
ZERO_BID > LOCKED > CROSSED > ZERO_SIZE > STALE > VALID
```

`ZERO_BID` covers every `bid_px <= 0` failure. `LOCKED` covers exact
`ask_px == bid_px`; `CROSSED` covers `ask_px < bid_px`; `ZERO_SIZE` covers
either size below one; and `STALE` applies only when exact age is greater than
2.0 seconds. The 2.0-second boundary is inclusive. This precedence makes the
single reason code deterministic and does not change quote eligibility.

The classifier ignores `quote_condition`, `sequence_no`, `source`, and
`raw_file_id`; does not mutate the frozen DTO; and does not emit `MISSING`,
`OUT_OF_ORDER`, `DUPLICATE`, `HALTED`, or `UNKNOWN`. No
`select_asof_quote(...)` function or multi-record behavior exists in S2.04.
