## 6. Implementation Details

The public stage API is exactly:

```text
CanonicalMinuteReturnIntegrityError
build_canonical_minute_return_series(session_state, bars)
```

The builder returns `tuple[float, ...]` with exactly 240 finite values in
chronological return-end order from 09:31 through 13:30 ET. It derives the
canonical open and decision timestamps through the existing DST-aware
temporal primitives and does not require `is_full_session=True`.

Bars from another session date, pure pre-open bars ending at or before 09:30,
and bars ending after 13:30 are filtered before grid, duplicate, quality,
source, price, or numerical inspection. A fully available active-window bar
must match an exact canonical minute interval. Therefore 09:29:30–09:30:30
hard fails, while 13:29:30–13:30:30 and 13:30–13:31 are non-observable.

Exactly one VALID required bar must exist for every canonical end timestamp.
Missing, duplicate, off-grid, or mixed-source required bars hard fail.
Multiple `raw_file_id` values from the same source remain allowed. The first
required bar open must equal `session_state.spx_open`, and the final required
bar close must equal `session_state.spx_decision_px`.

The first return is the natural logarithm of the 09:31 close divided by the
09:30 session open. The official previous SPX close is not read or used.
Every later return is the natural logarithm of the current close divided by
the immediately preceding canonical close. The final return is 13:29 close
to 13:30 close. Prices actually used are converted from Decimal boundaries to
finite positive float values; results are DOUBLE-compatible Python floats and
are not annualized or rounded.

Canonical implementation facts:

- Return type: `tuple[float, ...]`
- Return count: 240
- First return: 09:30 OPEN -> 09:31 CLOSE
- First denominator: `spx_open`
- Previous official SPX close used: NO
- Later returns: consecutive close-to-close
- Final return: 13:29 CLOSE -> 13:30 CLOSE
- Final allowed bar: 13:29–13:30
- 13:30–13:31 read: NO
- Incomplete 13:29:30–13:30:30 read: NO
- Opening-boundary malformed fully available bar: HARD FAIL
- Missing required bar: HARD FAIL
- Duplicate required bar: HARD FAIL
- Required quality: `QualityStatus.VALID`
- Mixed required source: HARD FAIL
- Multiple `raw_file_id` values from the same source: ALLOWED
- Final 30 return mapping: 13:00 -> 13:30
- `returns[-30]` end: 13:01
- `returns[-1]` end: 13:30
- Numerical output: FLOAT / DOUBLE-COMPATIBLE
- Natural log: YES
- Annualized: NO
- Rounding: NO
- x5: NOT COMPUTED
- x6: NOT COMPUTED
- x8: NOT COMPUTED
