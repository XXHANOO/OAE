### x5 — Thirty-Minute Realized Volatility

```text
x5 = sqrt(sum(r^2 for final 30 canonical returns))
source = dataset.canonical_minute_returns[-30:]
first included = return[210], 13:00 CLOSE -> 13:01 CLOSE
last included  = return[239], 13:29 CLOSE -> 13:30 CLOSE
return[209]    = 12:59 CLOSE -> 13:00 CLOSE, EXCLUDED
annualized     = NO
RMS            = NO
standard deviation = NO
```

### x6 — Intraday Realized Volatility

```text
x6 = sqrt(sum(r^2 for all 240 canonical returns))
source = dataset.canonical_minute_returns
first included = 09:30 OPEN -> 09:31 CLOSE
last included  = 13:29 CLOSE -> 13:30 CLOSE
return count   = 240
annualized     = NO
```

### x7 — Intraday Range Position

```text
x7 = (S_t - L_t) / (H_t - L_t + 1e-8)
S_t = dataset.session_state.spx_decision_px
H_t = dataset.session_state.intraday_high_to_t0
L_t = dataset.session_state.intraday_low_to_t0
range recomputed from bars = NO
epsilon = 1e-8
H_t == L_t = ALLOWED
zero-range result when S_t == H_t == L_t = 0.0
clamping = NO
```

### x8 — Trend Efficiency

```text
x8 = abs(ln(S_t / S_o))
     / (sum(abs(r_j) over all 240 canonical returns) + 1e-8)
S_t = dataset.session_state.spx_decision_px
S_o = dataset.session_state.spx_open
return source = dataset.canonical_minute_returns
return count = 240
return recomputation = NO
previous official close used = NO
absolute numerator = YES
epsilon = 1e-8
clamping = NO
```

float, finite, unrounded, and unannualized. Boundary market prices remain
Decimal and are converted only for derived feature arithmetic.
