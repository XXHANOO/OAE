## 6. Implementation Details

`_canonical_decimal_text(...)` uses `Decimal.as_tuple()` directly, rejects
non-finite values, collapses positive and negative zero to `"0"`, removes
trailing coefficient zeros while adjusting the exponent, and emits plain
decimal text without depending on the active Decimal context.

`_normalize_for_config_hash(...)` applies the required recursive type-check
precedence. It rejects non-string mapping keys, unsupported objects, and
non-finite Decimal/float values. It preserves sequence order and represents
enums, times, Decimals, and floats with the exact tagged structures prescribed
by the task.

`_canonical_config_bytes(...)` starts from
`config.model_dump(mode="python")`, normalizes recursively, then uses the exact
compact, sorted, UTF-8 JSON serialization contract. `compute_config_sha256(...)`
hashes only those canonical bytes. `validate_frozen_v0_1(...)` compares the
computed digest by exact equality with the static
`FROZEN_V0_1_CONFIG_SHA256` code mirror and includes both expected and actual
hashes in its `ValueError` on drift.

The validator does not mutate or repair the model, load another file, compare
raw YAML bytes, provide defaults, or use approximate numeric equality.

## Normalized Configuration Identity

- Canonicalization: OAE CONFIG CANONICALIZATION v1
- Input: `FrozenConfig.model_dump(mode="python")`
- Mappings: Recursive JSON object
- Sequences: `list`/`tuple` to ordered JSON array
- Enums: `{"$enum": value}`
- Times: `{"$time": isoformat(timespec="microseconds")}`
- Decimals: `{"$decimal": context-independent canonical decimal text}`
- Booleans: JSON booleans
- Integers: JSON integers
- Floats: `{"$float": float.hex()}`
- Strings: JSON strings
- None: JSON null
- JSON: `sort_keys=True`, `separators=(",", ":")`,
  `ensure_ascii=False`, `allow_nan=False`
- Encoding: UTF-8

reviewable frozen configuration identity. It is not a digital signature or a
