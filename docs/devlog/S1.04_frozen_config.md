## 6. Implementation Details

`StrictModel` uses `ConfigDict(extra="forbid", frozen=True)` without global
Pydantic strict mode. Every configuration field is required and has no Python
default. Pydantic therefore parses the YAML boundary values while missing or
unexpected fields fail validation.

`load_config(path: str | Path) -> FrozenConfig` reads UTF-8 text, calls
`yaml.safe_load`, explicitly rejects a non-mapping root, validates through
`FrozenConfig.model_validate`, and returns the immutable model. It has no
fallback path, mutation, override, default injection, or hash behavior.

The tests use one complete expected parsed mapping covering every leaf value.
They keep the test-only comparison local to the test module; no production
normalization or serialization format was created.
