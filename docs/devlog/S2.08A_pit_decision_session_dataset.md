`PITDecisionSessionDataset` is a frozen slots dataclass with exactly:

```text

```

The builder first calls `build_spx_session_state(...)` with the supplied
session, exact caller bar sequence, and explicit official previous close. It
uses that exact returned `IndexSessionRecord`. It then calls
`build_canonical_minute_return_series(session_state, bars)` exactly once and
uses that exact returned tuple. Call-spy regressions prove both calls, argument
identity, invocation count, and returned-object reuse. Session-state scalars
and minute-return mathematics are not independently reconstructed.

Only after both authoritative upstream builders succeed, the builder extracts
the exact target-date intervals from 09:30-09:31 through 13:29-13:30 in
chronological order using the DST-aware temporal helpers. It performs only
defensive bundle-integration assertions for the exact 240 counts, exact
interval grid, exact 13:30 decision endpoint, and session-state boundary-price
agreement. Existing `SPXSessionStateIntegrityError` and
`CanonicalMinuteReturnIntegrityError` instances propagate unchanged;
`PITDecisionSessionDatasetIntegrityError` is reserved for impossible
post-validation integration conditions.
